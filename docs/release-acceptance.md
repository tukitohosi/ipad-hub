| 项目 | 结果和范围 |
| --- | --- |
| 原始源码与回退基线 | 两项目当前源快照、发布哈希、原副屏未提交内容、37 份原数据文件与 14 个注册表值已保存 |
| 原 MouseLink 回归 | 166 项 Python 测试、9 项 Qt 检查通过；使用新项目中的源码副本 |
| C++ 后台 | 独立 Release 构建通过；12 项 CTest 通过，包含原 10 项与新增 JSON/命名管道测试 |
| 后台资源交接 | 主控制器通过 50 次模拟往返、取消、迟到事件、异常退出与停止失败阻断；必须同时收到释放确认和正常进程退出 |
| 真实空管道联调 | Qt 宿主分别与 Python/C++ 子进程完成状态与关闭联调；未开始真实设备会话 |
| 键鼠与固件 | 后台参数、占用拒绝、校准左右位置同步、保存失败、固件仅备份不擦写的回归通过；底层硬件动作使用替身 |

| 界面 | 用户已确认美化版；明暗、按钮与键盘、长设备名、最小窗口和缩放有本机自动检查 |
| 生产界面启动 | 五页可创建，首次打开首页，不自动启动后台；隔离目录自检不执行迁移 |
