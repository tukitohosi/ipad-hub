# iPadHub 验收记录

## 0.1.1-preview

2026-11-14 的 Windows 本机测试覆盖以下内容。

- 副屏布局的验收项为“iPad 副屏”页的“连接方式”下方显示“副屏位置”，选择左右后核对 Windows 扩展桌面的排列；单独检查“键鼠控制”页原有的边缘方向与设置读回。实测结果记录于本次发行报告。
- 从原自定义 60 帧 / 100 Mbps 点击三个预设，再回选自定义。界面、配置与后台目标参数均经过检查。
- 连接中连续点选、停止或退出取消重连、后台退出后的资源交接，以及失败处理。自动化使用模拟接收端或无设备管道。
- Windows 实际鼠标采集登记与释放、慢中快三档采样换算、校准与手动速度切换、发送受阻时继续采集、拖拽和键盘顺序、边缘确认。两屏实际距离与 iPad 端手感需分别记录真机结果。

本版安装器、便携包、对应源码和 SHA-256 清单位于 `release/0.1.1-preview/`。打包后的启动、升级、清理及真机记录以此次发行随附的验收结果为准。

### 公开发布时补充的结果与限制

- 用户在真实连接中验证副屏左 / 右布局与跨屏拖窗，键鼠方向仍为独立设置。
- Wi-Fi 真机会话使用自定义 60 帧 / 100 Mbps 目标配置；本次核对连接配置，实际帧率与吞吐未作专项验收。三个预设切换的自动验证通过，不据此认定持续传流通过。
- 用户反馈三档速度向导的匹配手感仍未达到预期；本次没有测得两屏鼠标物理距离的误差，10% 目标尚未验证。本次发布保留用户试用的冻结版本。
- 隔离 QA-only 安装器已实际完成旧版安装、新版沿用自定义目录升级和卸载，模拟设置 / 校准 / 固件备份保持不变。此结果不替代正式 AppId 在干净 Windows 的验收。
- Windows pacing 报告仅为 Windows 调度微基准，无 iPad、输入钩子或硬件报文，不能用于判断 iPad 实测刷新率、吞吐或两屏距离误差。

公开资产与准确哈希见 [发行说明](releases/0.1.1-preview.md)。以下 0.1.0 历史记录的未验证项目保留历史语境。
