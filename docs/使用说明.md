# iPadHub 0.1.0-preview 使用说明

iPadHub 将 iPad 副屏和键鼠控制放在一个应用中，第一版一次使用一种功能。安装它不需要卸载 MouseLink 或 iPad互联，两个旧应用及其快捷方式继续保留。

## 安装和打开

运行 `iPadHub-0.1.0-preview-Setup-x64.exe`，按向导安装。默认安装位置为 `%LOCALAPPDATA%\Programs\iPadHub`，开始菜单和可选桌面快捷方式名为 iPadHub。便携版需要完整解压后打开 `iPadHub.exe`，保留同目录的文件和文件夹。

首次打开会将旧设置、设备记录和固件备份复制到 `%LOCALAPPDATA%\iPadHub`。之后使用新应用独立保存的数据，不反向覆盖旧软件。首页不会自动连接或接管键鼠。

## 将 iPad 用作副屏

1. 在 iPad 打开 OpenDisplay 并保持前台。Windows 需要已经安装可用的虚拟显示驱动；本安装包不包含或安装 Parsec 驱动。
2. 打开“iPad 副屏”，点击“刷新设备”。USB 连接还需要 Windows 上可用的 Apple 设备服务；Wi-Fi 需要可用的私有局域网。
3. 选择设备、自动/USB/Wi-Fi 和画质，然后点击“连接副屏”。可通过“手动地址”输入 OpenDisplay 的 IPv4 地址或本地主机名。
4. 界面只有收到实际传流状态才显示“正在使用”；发现 USB 或显示已记录设备不等于接收端已准备完成。
5. 若提示未注册分辨率，展开高级设置，点击“配置副屏分辨率”，按接收端报告填写宽高并接受 Windows 管理员确认，然后重新连接。驱动仍需自行安装；此按钮仅配置支持的尺寸。

“Windows 显示设置”可调整显示排列。第一版跟随 iPad 原生尺寸。旧版 iPad互联正在占用副屏时，请先从其托盘退出，再在新应用连接。

## 使用电脑键鼠控制 iPad

1. 连接已有的 ESP32-C3 开发板，并保持它与 iPad 的蓝牙配对。
2. 打开“键鼠控制”，点击“刷新设备”，检查 USB、蓝牙及定位通道状态。
3. 选择 iPad 在电脑左侧或右侧，点击“开始键鼠控制”。速度、自由/锁定模式和可选校准在高级设置中。
4. 紧急返回电脑使用 **Ctrl + Alt + Esc**。锁定模式也支持 Ctrl + 左 Alt；自由模式可单独开启这个返回组合键。

日常使用不要求重新刷机或校准。若需要校准，请停止控制、刷新开发板，确认就绪后使用“可选校准”。校准会移动光标检查七个位置，由你确认后保存结果。

旧 MouseLink 正在运行时，新应用会提示退出旧托盘后再试。请勿让两个程序同时使用同一块开发板。

## 切换、退出与设备工具

从一种用途切换到另一种用途时，应用会先停止当前后台，确认资源已释放且进程退出后再启动目标用途。无法确认释放时禁止切换，并提供重试停止及人工检查入口。停止超时时，请按界面提示重试或检查设备占用。

设备工具提供仅备份固件、刷写、恢复和诊断。仅备份不擦除或刷写；刷写/恢复会先创建备份，仍需在工具窗口确认操作。工具打开期间禁止启动连接。刷写中请保持 USB 连接，退出会等待操作完成。

关闭主窗口收起到托盘；托盘“退出”或 Ctrl+Q 会停止后台并退出。Alt+1 至 Alt+5 切换页面，窗口内 Esc 取消连接或停止。分辨率配置过程中退出会等待助手结束。

## 数据与回退

- 新数据：`%LOCALAPPDATA%\iPadHub`，设置页可直接打开。
- 两种功能的设置分别在 `display` 与 `mouselink`；固件备份在 `firmware-backups`。
- 迁移只复制。新文件已存在时不会被旧设置覆盖；失败可用默认设置，并在下次启动重试未完成项。
- 回退时退出 iPadHub，使用原来的 MouseLink 或 iPad互联快捷方式即可。
- 卸载 iPadHub 默认保留新用户数据，不调用两个旧应用的卸载程序。
