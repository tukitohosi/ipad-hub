## 已落实的真实接入顺序

1. 先给两个引擎明确独立数据路径与日志路径。副屏位置注册表改为 `HKCU\Software\iPadHub\Display`；旧位置只复制，禁止调用会删除旧共享坐标的兼容迁移。
2. 键鼠从 Worker 抽取无窗口接口；停止模式时执行 `request_shutdown()` 并等待串口、全局钩子、按键和鼠标约束全部释放。不能把 `stop_bridge()` 当作进程已退出。
3. 副屏抽离 `TrayApp` 中发现、连接协调、配置与生命周期；复用 `SenderApp`、编码、传输和 OpenDisplay 协议。`Stop()` 完成且虚拟屏和输入释放后才报告停止成功。
4. 新增本机管道入口与版本化 JSON，命令携带请求和会话标识。日志与控制分离；验证父进程退出、管道断开、超时与迟到事件。新 UI 使用真实确认驱动模式状态机。
5. 实现一次性复制迁移、标记和损坏恢复；副屏设备身份、开发板身份分开。保留旧文件、旧注册表和旧备份，重启不覆盖已迁移设置。
6. 保留底层设备/VDD/串口互斥；旧程序占用时明确提示。固件助手运行期间锁住用途切换；停止失败时禁止另一个模式启动。
7. 接真实设备前完成新增自动回归，再做下表真机与安装验收，逐项记录结果。
