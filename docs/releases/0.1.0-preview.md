# iPadHub 0.1.0-preview 发布与验收报告

发布日期：2026-09-30。平台：Windows x64。类型：整合预览版（Prerelease）。

本版本把 MouseLink 的 Python 键鼠后台与 iPad互联的 C++ 副屏后台接入统一 PySide6 界面。第一版一次使用一种用途，等待当前后台确认资源释放并正常退出后再启动目标用途。安装身份、设置目录与副屏注册表路径独立，旧应用和旧数据保留。

## 尚未验证

- 真机两模式往返至少 50 次；模拟往返不计为真机验收。
- USB 副屏、Wi-Fi 副屏、键鼠控制分别持续 60 分钟。
- 卡键、串口残留、额外虚拟屏、紧急返回、接收端前后台、断连、锁屏和睡眠恢复。
- 实机固件刷写 / 恢复、分辨率助手执行、全部新旧软件同时占用场景。
- 干净 Windows 安装、普通用户使用、实际安装 / 升级 / 卸载及数据保留。
- 跨显示器 DPI、读屏与系统主题实时切换的完整验收。

## 使用条件、许可与回退

副屏需 iPad 上的 OpenDisplay 与 Windows 已配置的虚拟显示驱动；USB 另需 Apple 设备服务。键鼠控制需兼容 ESP32-C3 开发板及 iPad 蓝牙配对。本安装包未签名，不嵌入或自动安装 Parsec 驱动，不修改防火墙。

整合产品按 GPL-3.0 交付对应源码，各组件保留 MIT、GPL、LGPL 等原许可；Qt DLL 独立分发，第三方许可全文随包提供。

默认安装在 `%LOCALAPPDATA%\Programs\iPadHub`，新数据在 `%LOCALAPPDATA%\iPadHub`。迁移只复制，卸载默认保留新数据。回退时退出 iPadHub，使用原 MouseLink 或 iPad互联即可。
