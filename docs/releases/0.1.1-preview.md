# iPadHub 0.1.1-preview 发行说明

发布日期：2026-11-14。Windows x64 整合预览版。

把 iPad 副屏与 ESP32-C3 键鼠控制放进同一个应用；一次使用一种功能，切换前等待当前后台释放资源并退出。

## 本版变化

- 在“iPad 副屏”页的“连接方式”下方选择“电脑左侧 / 电脑右侧”，调整 Windows 扩展桌面；键鼠进入边缘仍在“键鼠控制”页独立设置。真实连接的左右布局和拖窗已验证。
- 一键画质为流畅 15、均衡 30、清晰 45 Mbps，均以 60 帧为目标；保留原自定义画质。连接中更换档位会重连同一台 iPad，停止或退出可取消重连。
- 键鼠采集与发送分离，新增鼠标速度向导，支持显示器可视尺寸、iPad 尺寸及慢 / 正常 / 快三档采样。

**已知问题：本轮试用的鼠标匹配手感仍未达到预期。本次没有测得两屏物理距离的误差，10% 目标尚未验证。速度向导按试验功能提供，本次发布保留用户试用的冻结版本。**

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| `iPadHub-0.1.1-preview-Setup-x64.exe` | Windows x64 安装版，可升级已有 iPadHub；默认安装到当前用户的程序目录 |
| `iPadHub-0.1.1-preview-Windows-x64.zip` | 便携版；完整解压后运行 `iPadHub.exe`，保留同目录全部文件 |
| `iPadHub-0.1.1-preview-source.zip` | 与安装版、便携版对应的冻结源码，亦嵌入发行程序中 |
| `SHA256SUMS.txt` | 本次实际公开资产的 SHA-256 清单 |

安装器未签名，不内嵌或自动安装 Parsec 驱动，不修改防火墙。副屏需要 iPad 上的 OpenDisplay 和可用的 Windows 虚拟显示驱动，USB 另需 Apple 设备服务。键鼠控制需要兼容 ESP32-C3 通过 USB 连接电脑，并与 iPad 蓝牙配对。

首次运行只复制兼容旧设置和固件备份；新旧应用各自保留数据，卸载默认保留 iPadHub 用户数据。原 MouseLink / iPad互联可以保留，使用同一设备前请先退出另一应用。紧急返回电脑使用 **Ctrl + Alt + Esc**。

## 实际验证范围

- 最终 C++ Release 构建、12 项 CTest、111 项 iPadHub Python 回归通过；固件资源、冻结主界面和两个后台的无设备状态 / 退出握手通过。
- 源码 ZIP 共 1,314 文件，便携包清单覆盖 291 文件；ZIP CRC、内嵌与外置源码相同、文件哈希和许可检查通过。便携版在仅含系统目录的 PATH 下独立启动，不调用项目 Python。
- 隔离 QA-only 安装器完成旧版安装、新版升级、复用自定义目录及卸载；模拟设置、校准与假固件备份保持不变。该验证采用同一正式 Inno 定义及原始便携载荷，仅改变隔离安装身份、路径和快捷方式数据参数。**不等于正式 AppId 在全新 Windows 的真实安装 / 升级验收。**
- 真机已确认副屏左右布局和跨屏拖窗。真实 Wi-Fi 会话采用自定义 60 帧 / 100 Mbps **配置目标**；本次核对连接配置，实际帧率与吞吐未作专项验收。三个画质预设通过配置与模拟切换验证。
- 50 次真机往返切换、USB / Wi-Fi / 键鼠各持续 60 分钟、全部断连 / 睡眠恢复、实机刷写与干净 Windows 仍未完成验收。

`windows-pacing.json` 仅是 Windows 调度微基准，无 iPad、输入钩子或硬件报文。125 Hz 目标下，中位间隔由 15.70 ms 变为 8.35 ms，P95 由 16.14 ms 变为 8.62 ms；不能据此判断 iPad 端帧率、吞吐或鼠标物理距离误差。
